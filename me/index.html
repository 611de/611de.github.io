打工、躺着，以后

在外资银行打过工，在华为 OD 成都继续打工，打工人，打工魂，打工都是人上人。

打工靠 Python，靠 Java，还是 Python 牛啊，一群为爱发电的人，一个非盈利性组织。Python是世界上最好的语言。但我用 JavaScript，AI时代来了。代码都不需要人来看了。细看还是 JavaScript 写的最多，NodeJS也算是JavaScript 吧。虽然都是 Java 的业务代码。但一到要数据分析、加 AI 能力、做自动化报告的时候，就还得是 Python 出场了。但真到了客户端还得是前端来打底。

还干过硬件维护，OceanStor，存储服务器，很贵的。企业级存储，自己搞个U盘，搞个移动硬盘，搞个NAS顶天了。真存东西还得企业级服务器。回到代码开发后，只是时代确实变了，现在不太自己写代码了，AI 把代码写作全包了。后端工程师，变成了「全干工程师」。
